## Описание

Movie_Library — это простое приложение с графическим интерфейсом (GUI) для ведения личной коллекции фильмов. Пользователь может добавлять фильмы с указанием названия, жанра, года выпуска и рейтинга. Приложение поддерживает фильтрацию по жанру и году выпуска. Все данные сохраняются в файл `movies.json` и могут быть загружены обратно

## Технологии

Python 3.x.
Tkinter (GUI).
JSON (сохранение/загрузка данных).
Git (контроль версий).

Примеры использования (тесты)

*   **Тест 1: Добавление фильма**
    *   Заполните все поля (например: *"Начало"*, *"Фантастика"*, *"2010"*, *"8.8"*).
    *   Нажмите «Добавить фильм». Фильм должен появиться в таблице.
*   **Тест 2: Валидация ввода**
    *   Попробуйте добавить фильм с пустым полем «Название». Должно появиться окно ошибки.
*   **Тест 3: Валидация рейтинга**
    *   Введите в поле «Рейтинг» значение `11` или `-1`. Должно появиться окно ошибки.
*   **Тест 4: Фильтрация**
    *   Введите в фильтр по жанру слово *"Комедия"*.
    *   Нажмите «Применить фильтр». В таблице должны остаться только фильмы этого жанра.
*   **Тест 5: Сохранение и загрузка**
    *   Добавьте несколько фильмов.
    *   Нажмите «Сохранить в JSON».
    *   Закройте программу.
    *   Запустите программу снова и нажмите «Загрузить из JSON». Данные должны восстановиться.
